# MAR-001B 预注册

复用 MAR-001 同一批 60 张开发图、三个 SHA-256 核验的 seed 0 checkpoint、原始标注总量、越界投影、前景区域及空间度量。只做 T1–T16 推理，T4 固定参照。F4 同时保留 T1 训练深度。主要决策为 F1 T8，F3 和 F4 分别报告，不用一个模型代表全部骨干。

按每位置最后轴分解 m、z。A 为 T4 全特征，B 为当前 z 配 T4 m，C 为 T4 z 配当前 m，D 为原轨迹读出。用对称两次序分配非线性计数差。贡献门采用 D>A 图上 mean Shapley 和除以正向人数增量和，保留逐图带符号的贡献及分位数。其他对照包括逐轮恢复 m4 的轨迹、保持 D 形状的固定 T4 总量、当前 z 搭配 m0，以及在 B 上逐位置将当前 centered 方向的 RMS 匹配至 T4。若源方向严格为零而目标非零，该 RMS 对照标记未定义。前后景按原 MAR-001 定义，softplus 近似报告锁定 −5、+5 两阈，背景穿越以 0 为阈。

每图从实际 x4 开始，反复执行原块并将新通道均值恢复至 m4。工程门核对原图预测、动量拆解、LayerNorm、残差块等变性、JVP 和逐轮锚定等价性。实时 FP32 对照以相对 RMS 3e−4、最大 logit 绝对差 .02、计数相对差 3e−4、JVP 相对误差 3e−4 为门。FP64 小模型相对容差 1e−10。随空间变化的公共通道偏移按 F4 全特征 RMS 乘以 .1 或 1，固定随机方向。JVP 用开发匿名 ID 排序的前三图，两个幅度均执行。Shapley 加和误差限 1e−8 人。

F1 T8 的计数定位门同时要求 B 移除至少一半新增 MAE、至少 60% 图绝对误差下降，以及正向人数增量中至少一半分配给均值路径。空间门要求相比 T4 的平均 GAME1 至少降 2%，且 TV 至少降 .01 或投影 W1 至少降 .005。所有区间用同图 2,000 次成对 bootstrap，种子事先锁定。门不用于启动新训练或其他架构实验。GPU 上限 3,600 秒。[Issue #13](https://github.com/xinnan369/sdr-mamba/issues/13)
