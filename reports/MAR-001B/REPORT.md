# MAR-001B | 通道均值漂移与密度读出的反证

## 范围与分解

以 MAR-001 PR #12 的 `454ba1d55a7f1324aeed044bd4468b885f8d89dc` 为基线。复用了同一旧开发 60 图、7,471 个标注、同一 seed 0 的 F1/F3/F4 冻结权重和相同的计数、越界投影、投影 W1 与前景定义。每个图像和原始标注的 SHA-256、每组 checkpoint 的 SHA-256 均与 MAR-001 一致。主参照固定 T4，F4 同时记载真实训练深度 T1。研究对象限于已观察开发集，训练新模型、内部确认、官方测试与 MAR-002 均为 `NOT_RUN`。[研究指令](https://github.com/xinnan369/sdr-mamba/issues/13) · [预注册](PREREGISTRATION.md) · [数据](data_manifest.json) · [权重](checkpoint_manifest.json)

在每个位置分解最后通道轴得到标量均值 m 和中心化向量 z。F1/F3/F4 的块沿 64 个通道计算 LayerNorm，残差块的变换读取归一化特征，未再归一化的密度头读取整个残差流。实数情况下，加任意逐位置公共通道偏移不影响归一化变换，残差恒等支路会保留它。线性读出的均值项为 `sum(w)·m`，中心化项为 `wᵀz`。这一中性方向和实际计数误差增长是不同现象。真实密度经 softplus，使用 A=(z4,m4)、B=(zt,m4)、C=(z4,mt)、D=(zt,mt) 比较，计数增量在两种顺序间取平均分配。两项的加和等于 D−A，交互被对称分配。

|---|---:|---:|---:|---:|---:|
| F1 | −4.2969 | 1.1489 | .5527 | .5337 | .2598 |
| F3 | −4.2946 | 1.4592 | .6293 | .6023 | .2899 |
| F4 | −4.2880 | 1.3015 | .5794 | .5561 | .2808 |

读出能感知公共均值。均值对计数的实际影响还取决于漂移大小、位置和工作区间。[读出权重统计](head_stats.csv) · [逐图分解](logit_decomposition.csv)

## 等变性及锚定验证

在非方形小模型上对 F1/F3 两类块实际测试 FP64、FP32 及 .1、1 两个扰动幅度。LayerNorm、残差、JVP、锚定后特征和读出的最大相对 RMS 误差分别在 FP64 为 6.29e−16 以内，在 FP32 为 3.41e−7 以内。测试还覆盖零和读出权重、图之间隔离、RMS 对照退化分支。全套 71 项通过、3 项条件跳过。[小模型日志](equivariance_small_log.txt) · [全套测试](test_log.txt)

三个真实模型共 360 次公共通道偏移测试。LayerNorm 和残差等变性的最大相对 RMS 误差为 1.73e−7 与 6.19e−7。18 个真实方向 JVP 的记录均为通过，偏移方向在执行精度内为恒等。逐轮从实际 x4 开始运行原块并恢复 m4，与只改读出的 B 比较。T4–T16 的 2,340 对中，中心化特征和分支更新的最大相对 RMS 差为 2.34e−7 与 1.65e−6，输入归一化结果为 2.51e−7。锚定读出最大绝对 logit 差 7.63e−6，最大计数相对差 1.32e−7。解析 logit 增量拆分最大差 1.14e−5，Shapley 人数最大加和误差 1.46e−11。2,880 条原轨迹计数和 MAR-001 逐条一致。工程门为 **PASS**。中性 JVP 仅针对公共通道方向，无法证明其他方向或全局轨迹收缩。[等变性](equivariance.csv) · [JVP](jvp.csv) · [锚定比较](anchor_equivalence.csv) · [独立复算](analysis_log.txt)

**研究门 FAIL。** 主要 F1 通过改善图比例门，但移除的新增 MAE 与 Shapley 均值贡献均低于各 50% 的门槛。正向增量中均值占比采用正向图的带符号均值贡献之和除以正向人数增量之和。60 图的 F1 平均带符号增量分配为均值 +115.43 人、中心化 +2,110.00 人，均值占比图间四分位 .0472/.0511/.0544。F3/F4 的平均带符号分配为 +79.88/+444.16 与 +10.83/+91.47 人。三个模型的均值与中心化 Shapley 在 T8 都为 60/60 图正值，幅度差异仍很大。F1 同图 bootstrap 的新增 MAE 移除比例 95% 区间为 [9.85%, 10.57%]，均值贡献比例 [5.03%, 5.35%]。F3/F4 的移除比例区间依次为 [28.31%, 32.17%] 和 [14.93%, 18.71%]。区间只描述已观察的开发图与固定权重。[计数门](gate.json) · [逐图反事实](counterfactual.csv) · [同图区间](bootstrap.csv)

与 T4 相比，F1 B 的 GAME1 为 1,993.55 对 47.46，TV 增加 .02206，投影 W1 增加 .01134。F3 B 的 TV 降 .01277，投影 W1 仍升 .01250，GAME1 由 52.76 升至 369.53。F4 B 的 GAME1 也由 65.77 升至 132.40，其真正训练深度 T1 的 MAE 是 41.09。三个模型固定均值后均未达到空间门。F1 在不足 25 人的 3 张图和至少 200 人的 11 张图的 B MAE 仍达 811.46 和 3,495.38。固定 T4 总量作为独立对照能保持计数误差，F1/F3/F4 的 T8 GAME1 仍为 50.02/55.32/67.01，高于各自 T4。[汇总](summary.csv) · [原始深度](per_image_depth.csv) · [计数分桶](count_bins.csv)

### 中心化变化与尺度对照

F1 T4 到 T8 的中心化特征 RMS 由 1.234 升至 1.641。T8 逐图后平均的均值 logit 增量 RMS 为 .100，中心化为 2.495。F3 同指标为 .930 和 5.231，F4 为 .048 和 .511。F3 的跨位置平均通道均值从 −.417 降至 −1.001，仍有正向的均值计数贡献。空间不均匀性与非线性读出下，平均激活的符号不足以推断聚合计数的响应。

在 F1 T8，约 8.07% 背景格和 34.66% 前景格相对 T4 从 logit ≤0 穿到 >0。F1 T16 有约 35.69% 全图格达到 logit ≥5。全轨迹中，logit ≤−5 时 softplus 相对于 exp 的最大差约 .335%，logit ≥5 时相对线性近似最大差约 .134%。两者之间采用真实 softplus。F3 T8 约 91.46% 的格仍在 logit ≤−5，阈值区间分布随骨干不同。[分区轨迹](logit_decomposition.csv)

额外读出诊断在固定 T4 均值的基础上，将每位置当前中心化向量的 RMS 匹配到 T4，保留方向。F1 T8 的 MAE 降到 119.53，GAME1 仍为 124.79，高于 T4。F3 与 F4 的对应 MAE 为 44.70 和 64.31，GAME1 为 54.01 和 72.53。该组合直接改变中心化输入到读出端的尺度，其结果不具备逐轮均值锚定的轨迹等价性。固定初始 m0 时，F1/F3/F4 在 T4 的 MAE 为 38.77/50.27/48.31，在 T8 为 2,038.95/277.83/109.12。保留两种固定参照，主门仍用预先登记的 m4。[全部读出对照](summary.csv)

## 去留

公共均值方向在本实现确实中性，且未归一化的密度头能读出它。干预表明，这一路径可解释部分误差，主导路径是当前检查点的中心化残差与读出耦合。依据预注册门结束通道均值主导假设的探索。该判断不外推到其他训练种子、归一化结构或预测反馈架构。

## 复现

本轮在已有 RTX 3090、PyTorch 2.5.1 / CUDA 12.4 上运行。共完成 2,880 条逐图深度记录、22,500 条反事实和 8,640 条分区记录，实测模型阶段合计 138.54 秒，最大 PyTorch CUDA 分配约 321.84 MiB。官方 SSD 仍沿用历史的 `NOT_RUN` 状态，本轮 SSM 使用已验证分块 oracle。配置、实现和正式运行提交为 `d8d8ee79bacf76e5c38ccf33dc905dad56fe2c56`，分析代码为 `9c1f091c51aabde4375ef39310ab6160173e7f4f`。本地路径在公开日志中以通用占位符表示。[环境](readout_environment.json) · [运行日志](readout_log.txt) · [资源](resource_log.csv)

在仓库根目录设置 `MAR001_DATA_ROOT` 为授权的本地 ShanghaiTech Part B 目录，`MAR001_PYTHON` 为现有 CUDA Python。若历史 checkpoint 存放于别处，设置 `MAR001_CHECKPOINT_HOME` 为含 `checkpoints` 子目录的位置。使用一个新输出目录。

```powershell
$env:PYTHONPATH = "src"

& $p -m pytest -ra -s
& $p -m scripts.run_mar001b --output $out
& $p -m scripts.analyze_mar001b --output $out
```
