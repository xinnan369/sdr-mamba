## 证据边界与可复用产物

- **工程事实。** 逐轮测试覆盖显式递推与分块 oracle 的输出、末态、初态梯度、非整块分组，两轮可微传播、轴向几何、数据隔离和密度计数守恒。CUDA fallback 的误差和环境日志可复核。官方 Mamba-2 SSD 一致性仍为 `NOT_RUN`，也缺少部署效率基准。[数学与 GPU 核对](SDR-005/gpu_chunked_parity_log.txt) · [安装](SDR-005/installation_log.md)
- **合成机制证据。** 匹配内部状态对已控制的近距种子与干扰确有影响。容量匹配、错配和特征基线收紧后，远距增益及 OOD 鲁棒性未建立。源样本、种子和哈希可重复，无法外推到真实对象空间推理。[反事实](SDR-002/counterfactual.csv) · [距离](SDR-004/distance_metrics.csv)
- **文献重合。** 既有视觉 SSM 已覆盖行列多方向扫描、共享外轮和多种内部状态复用。Arcee 直接公开相邻块之间视觉 SSM 末态用于下一块初态。MambaVLT 有跨帧末态；VMambaCC 已应用于人群计数。项目的端点映射实测应作为已知机制下的受控比较。[完整原文核查](SDR-005/literature_gap.md) · [Arcee](https://arxiv.org/html/2511.11243)
- **可复用工具。** 保存合成反事实数据生成与审计、轴向扫描逆映射和分块 oracle、同图/同种子成对复核、真实标注协议审计、质量守恒 target 与 crop 账本、独立确认集门控。公开证据以匿名图像 ID、文件哈希、配置和逐图指标为主，复现真实任务需要合法本地数据。

## 结项

交付负结果技术总结并停止当前项目的架构迭代。SDR-006 在已观察开发集取得较低误差与 46.7% 的总参数减少，但稳健性门失败，形成有限的单种子观察。EASR、LAST、BCST、SST 变体和 router 的冻结状态延续。海外依赖未获授权下载，官方 SSD 与官方测试继续标记 `NOT_RUN`。历史分割、检查点规定和不足分别保留。[末轮技术报告](SDR-006/REPORT.md)

若以后独立立项，优先研究明确标注协议和验证稳定性评估的可复用价值，例如在同一预训练许可、跨种子和预先保留的数据集上校准计数偏差。当前报告仅供技术复核和复用这些工具。
