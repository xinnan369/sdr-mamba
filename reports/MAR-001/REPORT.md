# MAR-001 | 密集预测的总量与空间深度诊断

**诊断完成，预注册研究门 FAIL。** 轴向 SSM 与循环卷积在训练深度之外均出现明显过计数。F1 的新增 Poisson deviance 主要集中在计数项，F3 的空间项与计数项都增长，计数项占优的图比例未达到门槛。固定 T4 总量后，两组 T8 的 GAME1 均恶化。结果支持对不同骨干分别诊断总量和空间误差，本轮证据不足以支持用总量控制换取更深推理的空间收益。[预注册](PREREGISTRATION.md) · [门判定](gate.json) · [Issue #11](https://github.com/xinnan369/sdr-mamba/issues/11)

## 预测量与对照验证

D 是每个 stride-8 单元的预测质量。用 FP64 求和得到 C，正预测的归一化形状为 P=D/C。真实头点直方图 Y 的总量 N 及形状 Q 同理。由逐单元广义 KL 独立复算 `N log(N/C)+C−N + N KL(Q||P)`。数值平滑仅向正总量下的 P 混合 `1e−8` 的均匀质量，保持 C 与归一化，原表达式也逐图保存。空 GT 只贡献 C 项。正 GT、零预测使总量项无穷。结构性零概率碰到正 GT 的原始式为无穷，测试覆盖这三个分支，真实运行均未出现。2,880 条实际分解最大绝对恒等误差为 1.46e−11，相对误差 5.43e−16。诊断前向在首图 T1–8 与历史模型接口逐值精确相符，15 个重合深度的开发 MAE 与历史聚合值最大差 1.98e−5（FP64 求和）。[分解明细](decomposition.csv) · [校验日志](analysis_log.txt) · [单元测试](test_log.txt)

归一化空间指标包含 TV（半 L1）与两尺度投影 W1。在 6×8、12×16 格上先无损聚合，再对 X、Y 及两条离散对角投影的 1D W1 按轴跨度归一化，取平均。该距离近似多轴搬移，局限于这些分辨率和投影。GAME1–3 仍受总量影响。背景为距真实点占用单元的 Chebyshev 距离大于 1 的区域，记录前景质量、背景质量、背景比例、归一化峰值与熵。另保存按 Y 或 D 总量加权的搬移差。

## 交付与复现

最终门的两项否决是跨骨干计数项主导和 T8 固定总量后的空间收益。可确认的是已观察开发集上的实测过计数和骨干间误差构成差异。空间收益不足，依据 Issue #11 停止当前扩展。MAR-002 保持未启动，历史 SDR 结果不改。

总计 2,880 条深度预测、2,880 条分解、14,400 条反事实、2,400 条隐层扰动观测和 36 条 JVP。完整单元测试 65 通过、3 跳过。RTX 3090 使用 PyTorch 2.5.1 / CUDA 12.4，记录的两个 GPU 阶段共 103.04 秒，模型阶段最大 PyTorch 已分配峰值约 289 MiB。深度代码与冻结配方提交为 `ccd309c5680244e8709e658d68ffccdcfc399148`，干预代码 `9572d898bc463dcfe58da6bcaa45bca601bbacc3`，分析及单元测试 `dc4987763bfd0ec025d262eb6e326505c20ba597`。[资源](resource_log.csv) · [深度环境](depth_environment.json) · [干预环境](perturbation_environment.json) · [运行日志](depth_log.txt)
