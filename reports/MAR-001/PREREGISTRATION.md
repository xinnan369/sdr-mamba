# MAR-001 预注册

本轮范围为已观察的 SDR-006 旧开发集 60 张图，冻结 checkpoint F1（轴向 SSM，训练深度 4）、F3（共享循环卷积，训练深度 4）、F4（轴向 SSM，训练深度 1）。按历史运行选择表核对 SHA-256。独立的开发读取器按匿名 ID 和哈希重新核对数据，只打开开发成员。原始计数、有限边界投影、原图和 stride-8 沿用 SDR-006。所有模型仅做评估，T=1…16，不训练。F1/F3 为跨骨干门控，F4 为训练深度不同的诊断。各 checkpoint 都是同一训练种子，开发数据已用于选点。

非负密度的总量用 FP64 求和。正预测下先严格归一化成 P，平滑仅用于广义 KL，将 P 替换为 `(1−epsilon)*P + epsilon/K` 并保存 C。原始 KL 单独记录零预测导致的数学无穷。空 GT 的总量项为 C，形状项为零，概率距离缺省。正 GT 和零预测的总量 KL 为无穷，形状未定义。GAME1–3 使用原尺寸等分，TV 与 L1 使用未平滑的概率。两种分辨率先保质量聚合，再沿水平、垂直和两条对角投影取平均一维 W1，按各轴跨度归一到 [0,1]。背景取真实标注占用单元 Chebyshev 邻域 1 之外。保存 C 加权、N 加权量并区分单位。

T4 是唯一参照。反事实用 T4 总量与当前形状、当前总量与 T4 形状、真实总量与当前形状，以及观测预测和 T4 常量参照。诊断重缩放不回灌隐层。逐轮记录特征幅度和均值中心化幅度、更新幅度、余弦、计数与密度更新。比较 T6 和 T8，不事后选深度。按同图 bootstrap 2,000 次，对增量报告百分位区间和按原始人数分层。

只看 F1/F3 的 T6/8。开发诊断门要求两个模型两个深度均有 ≥60% 图的绝对计数误差增长及 ≥60% 图的总 deviance 增长，并且在总 deviance 增长的图中 ≥60% 出现正向计数项增长且计数项增量大于形状项增量。形状保留门要求两模型两深度的平均 TV 增量 ≤.03、平均双尺度投影 W1 增量 ≤.015。进一步，空间 scaling 门要求形状保留通过，且两个模型 T8 的固定质量 GAME1 至少改善 2%，同时平均 TV 至少降 .01 或 W1 至少降 .005。计数项占优是数学诊断。`PASS` 只用于全部门过。

八张图从按原始计数排序后的等分层中取中心秩。固定 F4 隐层做相对全特征 RMS 为 .001/.01 的同幅度扰动。包含正负径向缩放、单步残差方向、空间均值为零的局部随机扰动和通道共享偏移。两类随机方向各三次，固定随机数，不用 GT 预测反馈。计算 0…4 步特征放大、预测计数变化和密度变化。前三个等分层抽样图做单步和二步方向 JVP，方向为局部扰动首抽样和径向正向。JVP 以二阶接口可用性为准，可在独立条件下记录 `NOT_RUN` 或失败。报告方向增益及与小幅有限差分的相符性，不估计谱半径。总 GPU 时间上限 3,600 秒；执行日志保留停止及失败。
