# SDR-004 | 逐线对齐的跨循环状态传输

## 结论

**LAST 通过 ID 的同容量对照，整体科学门失败。** T=8 时，选定的 dstate=4 在新鲜 ID 上的 IoU 为 **0.5461 ± 0.0396**。相对同容量 lane 错配和特征消息分别提高 **7.41** 和 **18.37** 个百分点，均为 3/3 种子同向。它相对原 SST 的嵌套 U 和分支 OOD 增益仅为 **2.10** 和 **0.42** 个百分点。三个测试分割均未达到远区召回增益门。强特征 L6 和全图行列 L7 的平均 IoU 均高于 LAST。结果支持物理索引对该实现的种子条件预测有作用，证据指向近区判别及抑制干扰，未建立长程传播优势。本轮到此停止。[原始判定](gate.json) · [逐种子数据](metrics.csv)

## 路线与历史

以 SDR-003 的报告提交 a71d6ce6e9721a87ee072b94ef38754ef5380fd7 为基础。SDR-003 保持 28 通过、1 跳过、15 成功运行、7,936 更新、117 条 IoU 可复算的历史记录。原 SST 延长到 T8 训练后，fresh ID 的 T8 IoU 从 .4201 到 .5881，远区召回从 .0001 到 .1554。嵌套 U 的 .3165 仍低于 1/3，BCST 只做了单种子诊断且远区召回为 0。本轮检验行列物理索引是否是造成瓶颈的因素，冻结 BCST、锚定和深度监督。[SDR-003](../SDR-003/REPORT.md) · [Issue #5](https://github.com/xinnan369/sdr-mamba/issues/5)

## 模型及算量

每个 4×4 窗口投影一次。四方向各将窗口分成 4 条长度 4 的序列。反向扫描只反转线内像素，行列编号始终是物理边界坐标。逆置换后按像素等权融合并做与 A1 相同的残差更新。内部状态银行形状为 `[B,Hg,Wg,4,k,heads,headdim,dstate]`，2 头、每头 8 通道。取上一轮固定银行的合法上游负载和本窗同向同线负载，权重分别为 0.30 和 0.20，首轮初态零。邻居缺失时保留本窗项。转弯要经过逐像素融合和下一轮投影。传输固定一跳，无 occupancy 门；闭合边界也可以通过状态。

| 组 | 与 LAST 的关键对照 | 参数 |
|---|---|---:|
| L0 | SDR-003 原 raster SST、垂直方向局部项 | 815 |
| L0b | raster，但换成同窗同方向局部项 | 815 |
| L1 | 线扫描，每轮零初态 | 713 或 815 |
| L2 | 上游项改成本窗同一条线 | 713 或 815 |
| L3 | 同物理编号接收上一轮上游末态 | 713 或 815 |
| L4 | 同一个合法上游窗，接收端 j 读源索引 (j+1) mod 4，仅排列 lane | 713 或 815 |
| L5 | 相同 lane、邻居、混合与 payload；以末尾 dstate 个读出 token 发消息，再加到下一轮前 dstate 个 x token，内态从零开始 | 713 或 815 |
| L6 | SDR-003 B5，一跳共享边界 MLP，按物理边界接收 token 注入 | 1,589 |
| L7 | 全图独立行列扫描，每轮 reset；可在一轮跨多个窗口 | 815 |

32×32 图像每轮均访问 4,096 个方向 token，即每个正式运行 100,663,296 次访问。Raster 为 256 条长 16 的序列，局部线模型为 1,024 条长 4 的序列；全图 L7 为 128 条长 32 的序列。FP32 下每窗每个方向的 raster、dstate=1、dstate=4 线负载分别为 256、256、1,024 字节。L5 与同容量 L3 负载相等。L6 每方向为 256 字节特征，L1/L2/L7 无跨窗外轮负载。

两次 dense matmul 的估计是每序列 (4L²(1+8D)) FLOPs，包含 prefix 与驱动聚合，排除投影、元素运算、exp 及内存搬运。每图每轮依次约 raster 8.65M、线 dstate=1 0.59M、线 dstate=4 2.16M、全图 17.30M。L6 的边界 MLP 在活跃轮另约 1.49M。参数匹配、负载匹配和扫描访问量匹配分别报告。相等 token 数不能推定等算量或设备开销。

RTX 3090 实测受工作站负载影响，按各次评估的中位数汇总。正式 T=16 每图前向时间 L0 约 6.54 ms、L3 dstate=1/4 为 2.29/2.07 ms、L6 为 2.85 ms、L7 为 2.13 ms，线组含诊断张量。L0、L3 dstate=1/4、L6、L7 的训练峰值分配约 261.3、151.4、266.3、245.8、231.6 MB，按各组最大次运行报告（1 MB = 10⁶ 字节）。并行分片和串行运行的计时均保留，不将这些时间用作控制负载后的速度对比。[延迟](evaluation_latency.csv) · [参数、扫描预算和显存](runs.csv)

## 数据和选型

七组分割先注册种子，分别是 128 张训练图和三个家族独立的 24 张验证、40 张测试图。每图 3 个独立 BFS 确认、等面积且互斥的通行分量。三个种子轮流将三个分量设为目标。模型只接触通行和种子的二值通道，组件、路径、距离和边界标签只用于监督、审计或评价。所有地图 SHA-256 全局唯一，并与 SDR-001/002/003 的历史测试图去重。七个全通行 IoU 均为 1/3。训练只用 ID 的带状图。OOD 固定为嵌套开口 U 与在锯齿域内接通随机曲折树枝的非平行分支。生成后独立检查恰有三个等面积组件以及 OOD 至少一个相邻占据窗间无实际接触的边界。

分量面积统一取 84–89 像素；每张图随机分配 0.35、0.55、0.75 三个目标偏心率秩。在有至少一个 d_grid≥4 目标像素的候选种子中，选择最接近目标秩的像素，平局由生成器种子决定。实际均值约 0.548–0.553。实际像素偏心率仍有明显差异，ID 测试 21–36、嵌套 U 24–73、分支 19–39；因此 OOD 差异仍混合实际路径长度与几何差异。仅嵌套 U 有拒绝，验证 1/25、测试 1/41，原因均为构造面积。

全网格曼哈顿用于物理上界。种子外轮传播半径至多 T−1 条窗边（L7 例外），实际 held-out 种子交换在共同上界之外的最大 logit 差为 **0**。目标窗图只有目标组件跨窗四邻接时才连边，同时可因窗内聚合缩短距离。像素距离用 BFS。目标窗桶的 IoU 仅衡量桶内区域，像素 BFS 桶报告目标 recall。转弯分层定义为不存在从 seed 到该目标像素的单一坐标轴通行线段，另按 d_grid 联合分层；它不等价于最短路实际转弯次数。[数据审计](data_audit.json) · [清单](data_manifest.json) · [距离分桶](distance_metrics.csv) · [同图种子交换](counterfactual.csv)

固定 train_T=8、末轮 BCE+soft Dice、AdamW 0.003、batch 4、共同采样顺序，最后一次更新为 checkpoint。预注册先做 seed 0、256 更新。两个容量的 L3 都在三个验证分割中胜过 L4。dstate=4 的 L3 在 ID、U、分支的 IoU 为 .5107/.3234/.4901，平衡分 **0.6524**；dstate=1 为 .4541/.2825/.3996，平衡分 **0.4638**。两者远区 recall 为 0。固定选择 dstate=4、再以两种容量都做配对验证，不用 held-out 选模型。正式训练覆盖九个组，含 L0b、L6、L7，并为 L3/L4/L5 增跑 dstate=1，合计每种子 12 个配置。三个种子各固定 768 更新。单次 T=16 测试轨迹读取 T=4/8/12/16，T>8 是外推。[选型规则](../../configs/sdr004_selection.json) · [筛选读数](screen_metrics.csv) · [选型判定](selection.json)

## 机制诊断

冻结 T=8 特征及本窗项，仅清零或错配邻居 lane。选定 LAST 在 ID 的 d_grid=4–7 桶（含背景）中，清零/错配的平均绝对 logit 变化为 .1033/.0338，概率变化 .00421/.00212，翻转率 0.142%/0.122%。同一远区内须转弯的目标像素，错配的 logit 变化 .1720、概率变化 .01961、翻转率 1.58%。这些是固定当前轮的即时变化，当前特征包含先前历史。按四方向和各 lane 加权汇总，ID 的开放/闭合合法物理边界上，错配使融合前扫描输出平均变化 .0875/.0362，缺失邻居为 0。闭合边界有直接状态读出影响，符合无门的实现。

ID T8 的 dstate=4 每 lane/head 保留因子中位数跨方向、lane、种子的均值 .543，范围 .069–.987；发送状态 RMS 与接收初态 RMS 的均值约 1.176/.500，初态读出与总输出 L2 比均值 .386。dstate=1 的相应值为 .783、2.388/.964、.316。保留率和初态贡献随头、lane、容量而变，统计本身不识别衰减机制。固定 Ft 干预与跨种子对照共同支持模型会用到物理对齐，长程误差仍集中于漏召回和深度外推。[干预](intervention.csv) · [每线与每头保留率](retention.csv)
